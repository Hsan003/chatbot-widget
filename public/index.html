What it can do

A support agent on every page of the site

The assistant answers customers' questions using the information each company provides, so visitors get help without waiting for a human.

Answers 24/7

Questions about products, prices, opening hours, delivery or returns get an instant answer, day or night.

Knows the business

Each assistant is given its company's own context: services, policies and tone of voice. It answers as part of the team.

Remembers the conversation

The assistant takes the whole conversation into account, so visitors can ask follow-up questions naturally.

Clear, formatted replies

Answers can include lists, bold text and links, which makes them easy to read at a glance.

Never clashes with the site

The widget runs in its own isolated layer, so the website's styles can't break it and it never changes the website's look.

Works everywhere

Lightweight and accessible on desktop and mobile, with screen-reader support built in.

Made for each company

Every setting belongs to the company

No two assistants look or talk alike. Each company sets up its own assistant, and the widget loads those settings automatically when the page opens.

Security

Protected by store ID verification

Each company receives a unique store ID. Every request is checked on the server before the assistant answers, so nobody can use or copy another company's assistant.

Unique store ID

The widget sends the company's store ID with every request it makes.

Verified on the server

The server checks that the store exists and its account is active. Unknown or disabled stores get no answer.

Approved websites only

The assistant only answers on the company's own approved domains. Copying the code onto another site doesn't work.

Abuse protection

Message limits per store stop spam and keep usage under control.

The assistant's instructions never leave the server Every server response is validated Protection against style injection Fails gracefully, never breaks the host site
